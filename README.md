# Charlie's (Algorithm) Angels: Breast Cancer Classification (CSCE 476/876)
## Final project for CSCE 476/876 Introduction to Artificial Intelligence,
University of Nebraska-Lincoln (Fall 2026). 
### Instructor: Prof. Leen-Kiat Soh.
### Team: Ella Goodrich, Eleanor Krause, Yin Po Po Aung, Aleksandra Stansbury.

## What this project does
We compare machine learning classifiers on the Wisconsin Diagnostic Breast
Cancer dataset (569 tumors, 30 measurements each) to reduce missed malignant
tumors (false negatives). Models: KNN (Euclidean, Manhattan, Chebyshev
distance), decision trees (ID3, C4.5, CART), SVM, and logistic regression.
